# Uso de IA en el Proyecto 3

## Herramientas utilizadas
- Claude
- Gemini

## Areas de uso
- Generacion de documentacion README.md
- Diseño del chatbot de Plotly Dash
- Explicacion de errores
- Refactorizacion de codigo

## Prompts representativos
1. En base a la siguiente documentacion, ayudame a generar una funcion que realiza X tarea
2. He entrenado el siguiente modelo, como puedo guardarlo en mi computadora para no tener que volver a entrenarlo?
3. Explicame ampliamente que significa cada parametro de esta funcion, dame ejemplos
4. Explicame por que obtengo el siguiente error cuando ejecuto este codigo...

## Como validamos las respuestas
- Comprobamos manualmente cada parte del codigo para verificar su correcto funcionamiento. Nos esforzamos en comprender el codigo generado.
- Se buscaron distintas fuentes

## Lo que NO delegamos
- Estrategia para de reglas del chatbot
- Estrategia de chunking
- Interpretacion de resultados
